# v1.8.1

## What's Changed

- The installer menu now shows invalid input as a red full-screen warning and waits for Enter before returning.
- Desktop shortcuts now install matrix-style icons in both scalable and 256x256 icon theme paths.
- The launcher icon cleanup now removes both icon locations during uninstall.

## Notes

- This is a fix release for the installer and desktop shortcut presentation.
- The application still installs the latest published release by default.
