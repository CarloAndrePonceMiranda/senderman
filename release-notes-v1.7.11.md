# v1.7.11

## What's Changed

- `Senderman APP` now uses its own matrix-style icon for the web panel.
- `Senderman Shell` now opens a command-oriented console for service actions and uses its own shell-style icon.
- `Senderman Tools` now opens `./install.sh` directly and uses its own configuration icon.
- The installer removes old launcher files and registers only the current three-app layout.

## Notes

- This release keeps the menu and launcher structure aligned with the Ubuntu applications menu.
- The three desktop entries are now visually and functionally distinct.
