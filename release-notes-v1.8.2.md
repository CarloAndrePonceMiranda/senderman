# v1.8.2

## What's Changed

- The installer menu now only accepts the simplified commands shown on screen.
- The shell menu now only accepts the simplified commands shown on screen.
- Invalid commands now show a red full-screen warning and wait for Enter.
- The APP launcher starts the web panel with `nohup` when needed and then opens the browser.

## Notes

- This is a fix release for the interactive menus and launcher behavior.
- The installer still installs the latest published release by default.
