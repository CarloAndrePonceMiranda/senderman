# v1.8.0

## What's Changed

- Added drag-and-drop upload support in the files section.
- Added folder navigation with breadcrumb support in the files section.
- Added per-file and per-folder download buttons in the files explorer.
- The files table now exposes upload and download actions directly from the UI.

## Notes

- This is a feature release, so the minor version has been bumped.
- Folder downloads are delivered as a zip archive.
