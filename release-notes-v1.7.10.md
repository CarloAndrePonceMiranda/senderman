# v1.7.10

## What's Changed

- Added a dedicated `Senderman Shell` launcher for service actions like start, stop, restart, status, enable, disable, and shutdown.
- Split the applications menu into three entries: `Senderman Monitor`, `Senderman Shell`, and `Senderman Configuration`.
- Updated the installer to register the three desktop entries and remove the older two-entry layout.
- Documented the new application split in `README.md` and `DEPLOY.md`.

## Notes

- `Senderman Monitor` opens the web panel.
- `Senderman Shell` opens the terminal-based service actions menu.
- `Senderman Configuration` opens the install/update/reinstall/uninstall menu.
